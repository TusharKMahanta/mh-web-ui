# Start Development Server

This workflow starts the Remix development server with hot module replacement.

## Steps

// turbo
1. **Start the development server**
   ```bash
   npm run dev
   ```

The development server will start on `http://localhost:5173` (Vite default) or the port specified in your configuration.

## Features

- Hot Module Replacement (HMR)
- Fast refresh for React components
- TypeScript type checking
- Tailwind CSS with JIT compilation

## Stopping the Server

Press `Ctrl+C` in the terminal to stop the development server.
